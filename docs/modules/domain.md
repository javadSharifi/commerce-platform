# Domain — دامنهٔ اختصاصی و تشخیص فروشگاه

> قبل از کار روی Domain Resolver، تأیید مالکیت، دامنهٔ پنل یا SSL این فایل را بخوان.

**تسک‌ها** — `P0.2.3`، `P0.3.6`، `P1.3.2` تا `P1.3.4`، `P3.1.4`، `P3.1.5`، `P4.3` و `P5.3`. [چک‌لیست پروژه](../../TASKS.md)

## مسئولیت و مرز

Domain ثبت دامنه، وضعیت تأیید، بررسی مالکیت و نگاشت Host معتبر به [Tenant](tenant.md) را پوشش می‌دهد. پنل اطلاعات DNS و وضعیت تأیید را نشان می‌دهد. صدور SSL و پشتیبانی Apex با زیرساخت هماهنگ می‌شود.

## داده‌ها و عملیات

| بخش | محدودهٔ ثبت‌شده |
| --- | --- |
| داده | `domains` برای دامنه، رابطه با فروشگاه و وضعیت تأیید |
| پنل | ثبت دامنه، نمایش رکوردهای لازم DNS و وضعیت، درخواست بررسی دوباره |
| Storefront | تشخیص Tenant از Host تأییدشده با Domain Resolver و کش حافظه‌ای کوچک؛ ۴۰۴ برای دامنهٔ ناشناس |
| داخلی | بررسی TXT مالکیت و وضعیت فعال‌سازی NS یا CNAME، صدور و تمدید TLS لبهٔ آروان و اعتبار HTTPS در Caddy |

## قواعد اجرایی

- ابتدا مالکیت دامنه بررسی می‌شود. وضعیت ثبت‌شده یا در انتظار تأیید، دسترسی به فروشگاه و مجوز صدور SSL ایجاد نمی‌کند.
- روش اتصال دامنهٔ ریشه NS Delegation است. زیردامنه در وضعیت پشتیبانی‌شده از CNAME Setup آروان استفاده می‌کند. دستور DNS از حساب آروان می‌آید.
- Host باید با دامنهٔ تأییدشده تطبیق داده شود. اعتماد به header پراکسی فقط طبق مرز اعتماد زیرساخت مجاز است.
- مدیریت دامنه به عضویت و دسترسی معتبر همان فروشگاه نیاز دارد. نگاشت کش‌شده و پاسخ Resolver باید همین محدوده را حفظ کنند.

## سناریوهای تست

- مالک، دامنه را ثبت می‌کند. تأیید DNS مطابق قرارداد، دامنه را برای همان فروشگاه قابل استفاده می‌کند.
- رکورد نامعتبر یا دامنهٔ تأییدنشده، فروشگاه را resolve نمی‌کند و مجوز SSL نمی‌گیرد. Storefront برای Host ناشناس ۴۰۴ می‌دهد.
- Hostهای تأییدشدهٔ A و B به فروشگاه‌های درست می‌رسند. مدیر A امکان مدیریت دامنهٔ B را ندارد.
- در P5، HTTPS لبه و origin برای دامنهٔ ریشه و زیردامنهٔ تأییدشده در حساب هدف آزموده می‌شوند.

## پیش‌نیازها و مراجع

RLS روی `domains` طبق D-24 و lookup طبق D-28 هستند. NS/CNAME و مسیر TLS در D-26 ثبت شده‌اند و روی حساب و DNS هدف بررسی می‌شوند. [تصمیم‌ها](../DECISIONS.md) · [ضدالگوی AP-12](../ANTI_PATTERNS.md)
