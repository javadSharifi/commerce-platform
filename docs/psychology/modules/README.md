# ماژول‌های سایت‌ساز روان‌شناس‌ها

ماژول مرتبط با تسک را از جدول باز کن. قرارداد واقعی REST و Schema با تکمیل تسک‌های طراحی و migration در مسیرهای [نقشهٔ پروژه](../PROJECT_MAP.md) ثبت می‌شوند. [چک‌لیست](../TASKS.md) · [تصمیم‌ها](../DECISIONS.md) · [سناریوهای پذیرش](../ACCEPTANCE.md)

| ماژول | مسئولیت |
| --- | --- |
| [پلتفرم](platform.md) | Tenant، دامنه، نشست، نقش، قالب، حریم خصوصی و زیرساخت |
| [کارگاه حضوری](workshops.md) | انتشار، ظرفیت، ثبت‌نام و لغو رویداد |
| [پرداخت](payments.md) | شروع، Verify، تطبیق، بازپرداخت و Snapshot |
| [نوبت‌دهی](booking.md) | تقویم درمانگر، سانس، درخواست، تأیید، لغو و جابه‌جایی |
| [دورهٔ ضبط‌شده](courses.md) | جلسات، خرید، مالکیت و پخش امن |
| [بلاگ و رسانه](blog-media.md) | انتشار محتوا، آپلود و کلاس‌های دسترسی فایل |
| [سیستم طراحی و قالب‌ها](ui-templates.md) | پکیج `packages/ui`، توکن‌های تم، تقویم شمسی و موتور چندقالبی سایت |

هر تخطی از محدودهٔ Tenant باید در API، SQL و تست ایزولاسیون پوشش داده شود. ماژول پرداخت با شناسهٔ خرید و سرویس کارگاه یا دوره کار می‌کند. ظرفیت و مجوز دوره در همان تراکنش نهایی‌سازی Verify اعمال می‌شوند. رسانه فقط هنگام درخواست پخش به منبع مالکیت یا انتشار مراجعه می‌کند.
