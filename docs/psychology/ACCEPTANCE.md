# آزمون پذیرش مسیر روان‌شناسی

برای هر سناریو، نتیجهٔ موفق و خطا، شناسهٔ تسک، محیط و شواهد بدون دادهٔ شخصی را ثبت کن. تست API و دیتابیس با PostgreSQL واقعی و نقش runtime اجرا می‌شود. تست مرورگر با دو Host و دادهٔ ساختگی اجرا می‌شود. نتیجهٔ Sandbox یا Adapter تستی فقط همان محیط را پوشش می‌دهد. [الگوی ایزولاسیون](../patterns/03-tenant-isolation-test.md) · [نقشهٔ راه](TASKS.md)

| شناسه | رفتار قابل مشاهده |
| --- | --- |
| PSY-A01 | A و B روی دو Host فقط دادهٔ خودشان را نمایش می‌دهند. Host نامعتبر خطا می‌گیرد. با ID یا header جعلی، API پنل و عمومی داده یا تغییری در Tenant دیگر ایجاد نمی‌کنند. نقش runtime RLS را دور نمی‌زند. |
| PSY-A02 | مالک کارگاه رایگان و پولی با زمان، مکان و ظرفیت منتشر می‌کند. کاربر مهمان ثبت‌نام را تکمیل و نتیجهٔ خودش را می‌بیند. ظرفیت صفر یا قیمت کلاینت نمی‌تواند ثبت‌نام معتبر ایجاد کند. |
| PSY-A03 | دو درخواست هم‌زمان برای صندلی آخر حداکثر یک رزرو زنده یا ثبت‌نام قطعی ایجاد می‌کنند. رزرو منقضی ظرفیت را آزاد می‌کند. تغییر ظرفیت، لغو و Verify هم‌زمان سقف را نمی‌شکنند. |
| PSY-A04 | Callback تکراری و اجرای مجدد Worker تنها یک پرداخت و اثر تجاری ثبت می‌کنند. مبلغ، پذیرنده یا Authority ناهماهنگ رد می‌شود. پس از timeout، وضعیت بلاتکلیف قابل تطبیق است. پرداخت تاییدشده پس از انقضا یا لغو به بازپرداخت می‌رود. |
| PSY-A05 | پیش‌نویس بلاگ در صفحه، فهرست، sitemap و رسانهٔ عمومی دیده نمی‌شود. مطلب منتشرشده و رسانهٔ معتبر در Host درست دیده می‌شوند. لغو انتشار صدور URL جدید را قطع می‌کند و URL قدیمی پس از TTL منقضی است. |
| PSY-A06 | نمونهٔ تصویر، فیلم و صوت روی باکت هدف آپلود می‌شود و پخش و seek کار می‌کند. فایل ناسازگار، اضافه‌حجم و فایل Tenant دیگر رد می‌شوند. استفادهٔ مجدد از URL موقت فایل منتشرشده را عوض نمی‌کند. |
| PSY-A07 | دو درخواست برای یک سانس فقط یک نگه‌داشت فعال دارند. تأیید و لغو مجوز و زمان را بررسی می‌کنند. جابه‌جایی به سانس پر، نوبت قبلی را از بین نمی‌برد. درمانگر نوبت دیگران را نمی‌بیند و خروجی عمومی فاقد نام و شماره است. |
| PSY-A08 | خریدار پس از Verify یک دسترسی همان دوره می‌گیرد. Retry اثر تکراری ندارد. آرشیو جلوی فروش تازه را می‌گیرد و دسترسی خرید قبلی برقرار می‌ماند. بازپرداخت صدور URL تازه را متوقف می‌کند. |
| PSY-A09 | کاربر مهمان، حساب دیگر و Tenant دیگر نمی‌توانند URL یا فایل خصوصی درس را بگیرند. URL کوتاه‌عمر با دسترسی معتبر تمدید می‌شود. مصرف خارج از سهمیه، URL مستقیم بدون امضا و استفادهٔ دوباره از کد بازیابی رد می‌شوند. |
| PSY-A10 | پیش از عرضه، TLS و جدایی Hostها، ثبت‌نام موبایل، callback در پذیرندگی منتخب، پخش باکت واقعی، عدم کش پاسخ‌های خصوصی و بازیابی پشتیبان تأیید شوند. برنامهٔ پشتیبانی و نتایج دو پایلوت واقعی نسخهٔ ۱ ثبت شوند. |
| PSY-A11 | بعد از فعال شدن کش HTML، ویرایش مقالهٔ A فقط URLهای متأثر همان Host را purge می‌کند و کش B پابرجاست. `no-store` برای پیش‌نویس، پرداخت، وضعیت، نوبت، حساب و پخش خصوصی در مسیر CDN هم مؤثر است. |

## سنجش قبل از عرضه

- دادهٔ شخصی در URL صفحه، query، sitemap، HTML کش‌شده، لاگ و داشبورد عمومی بررسی شود. لاگ Callback و رسانه با پارامترهای محرمانهٔ حذف‌شده ثبت شود.
- اعتبارنامه‌ها، مقادیر عملیاتی، رویهٔ انتشار و شرایط نگه‌داری داده را در محیط مجاز بررسی کن. مدارک پزشکی یا شرح حال در fixture یا تست زمینه ندارد.
- هر نسخه تست‌های فاز خود و رگرسیون نسخه‌های قبلی را اجرا می‌کند. خرابی بازیابی، نشت بین Tenant یا اختلاف مالی مانع عرضهٔ همان نسخه است.
