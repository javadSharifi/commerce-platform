# نقشهٔ راه سایت‌ساز روان‌شناس‌ها

فقط تسک‌های `PSY-*` به این محصول تعلق دارند. تسک بعدی از [وضعیت اجرا](PROGRESS.md) پیدا می‌شود. هر تسک کوچک را با سند ماژول، سناریوی پذیرش و پیش‌نیازهایش اجرا کن. پایان فاز یعنی مسیرهای پذیرش فاز در محیط توسعه یا تست تأیید شده‌اند. انتشار واقعی هر نسخه تأیید محیط هدف خودش را دارد. [بریف](PROJECT_BRIEF.md) · [تصمیم‌ها](DECISIONS.md) · [پذیرش](ACCEPTANCE.md)

| فاز | خروجی |
| --- | --- |
| `PSY-0` | زیرساخت، دامنه، پنل، احراز هویت و ایزولاسیون |
| `PSY-1` | نسخهٔ ۱، ثبت‌نام کارگاه حضوری و بلاگ |
| `PSY-2` | نسخهٔ ۲، نوبت‌دهی حضوری |

## PSY-0 — اسکلت قابل اجرا

[پلتفرم](modules/platform.md) · [نقشهٔ مسیرها](PROJECT_MAP.md)

- [x] PSY-0.1 ساخت یا بازاستفاده workspace ریشه، Go app مستقل، دو app Astro و PostgreSQL محلی. health check API و اجرای محلی سه app را تأیید کن.
- [ ] PSY-0.2 تدوین `docs/psychology/database.md` برای هسته بر اساس [مدل داده](DATA_MODEL.md). `tenant_id`، شناسه‌های ترکیبی، ترتیب قفل‌ها، زمان UTC و قواعد ریال را ثبت کن. Schema دامنه به‌صورت افزایشی در هر فاز تکمیل می‌شود.
- [ ] PSY-0.3 ساخت قرارداد سراسری `/v1`، جداسازی Public/Account/Admin و Callback در OpenAPI و تولید کلاینت typed. خطا، pagination و پاسخ‌های خصوصی را تعریف کن.
- [ ] PSY-0.4 ساخت migration نقش‌ها، `tenants`، دامنه‌ها، هویت پنل، عضویت و نشست با RLS و lookup محدود. `up/down/up` را اجرا کن.
- [ ] PSY-0.5 ساخت resolver دامنه و `WithTenantTx` با pool و sqlc. دو Host و یک Host تأییدنشده را با نقش واقعی آزمون کن.
- [ ] PSY-0.6 ساخت ورود، بازیابی و عضویت پنل، انتخاب Tenant و کنترل نقش در API. آزمون نشست مستقل، CSRF و خواندن یا نوشتن بین دو Tenant را اجرا کن.
- [ ] PSY-0.7 ساخت پوستهٔ RTL پنل و سایت، پروفایل مطب و تنظیم لوگو و رنگ یک قالب نسخه‌دار. خروجی عمومی فقط فیلدهای انتشارپذیر را نمایش دهد.
- [ ] PSY-0.8 تنظیم `make verify-psychology` برای build/vet/test Go و lint/typecheck/test بسته‌های مرتبط. اجرای CI و fixtureهای A و B را مستند کن.

**پایان فاز** — دو سایت محلی با Host جدا، پنل محافظت‌شده و تست ایزولاسیون نقش runtime کار می‌کنند. سناریوی `PSY-A01` تأیید شده است.

## PSY-1 — نسخهٔ ۱ · کارگاه حضوری + بلاگ

[کارگاه](modules/workshops.md) · [پرداخت](modules/payments.md) · [بلاگ و رسانه](modules/blog-media.md)

- [ ] PSY-1.1 تکمیل ERD و OpenAPI کارگاه، صندلی، ثبت‌نام، پرداخت و رسانهٔ بلاگ. چینش وضعیت‌ها، ماتریس نقش، TTL و ترتیب قفل را در قرارداد نهایی کن.
- [ ] PSY-1.2 ساخت migration و Queryهای کارگاه، ثبت‌نام و پرداخت با RLS. صفر صندلی، رزرو منقضی و تغییر ظرفیت هم‌زمان را آزمون کن.
- [ ] PSY-1.3 ساخت API پنل و عمومی برای پیش‌نویس، انتشار، پایان ثبت‌نام و لغو کارگاه. فهرست سایت فقط دادهٔ عمومی همان Tenant را بدهد.
- [ ] PSY-1.4 ساخت ثبت‌نام مهمان و رزرو اتمیک صندلی. رایگان فوراً قطعی شود و پولی اعلان انقضا و صفحهٔ پیگیری خصوصی بگیرد. POST تکراری و رقابت برای صندلی آخر را آزمون کن.
- [ ] PSY-1.5 ساخت `PaymentProvider`، Adapter تستی و زرین‌پال و شروع پرداخت با Snapshot ریالی. درخواست شبکه را بیرون تراکنش نگه دار و مسیر شروع با نتیجهٔ نامعلوم را پوشش بده.
- [ ] PSY-1.6 ساخت Callback، Verify و تطبیق نتیجه و ثبت موفقیت در یک تراکنش با کارگاه. Callback تکراری، mismatch و پرداخت پس از انقضا یا لغو را آزمون کن.
- [ ] PSY-1.7 ساخت پردازش محدود PostgreSQL برای انقضا و تطبیق پرداخت بلاتکلیف و صفحهٔ خصوصی مالک برای پیگیری `refund_required` و ثبت بازپرداخت. retry و crash recovery را بررسی کن.
- [ ] PSY-1.8 ساخت فرم کارگاه و پنل فهرست ثبت‌نام‌ها، صفحهٔ عمومی کارگاه، فرم و نتیجهٔ ثبت‌نام در موبایل. سناریوی پرداخت موفق، لغو و اتمام ظرفیت را از مرورگر اجرا کن.
- [ ] PSY-1.9 ساخت migration و API پیش‌نویس، انتشار و لغو انتشار بلاگ با slug یکتای Tenant. تزریق محتوای نامعتبر و دسترسی پیش‌نویس را آزمون کن.
- [ ] PSY-1.10 ساخت آپلود مستقیم پارس‌پک با staging خصوصی، فایل نهایی ثابت، اعتبارسنجی نوع و حجم، کلاس دسترسی و پاک‌سازی موقت. بازنویسی فایل، فایل نامعتبر و پیوند بین دو Tenant را آزمون کن.
- [ ] PSY-1.11 ساخت ویرایشگر امن بلاگ و صفحات فهرست و مطلب، پخش فیلم و صوت و sitemap per Host. پخش و seek و لغو انتشار را آزمون کن.
- [ ] PSY-1.12 آماده‌سازی Compose، Caddy، اعتبارنامهٔ جدا، دامنهٔ تأییدشده و CDN دارایی‌های ثابت. پاک‌سازی دوره‌ای دادهٔ ثبت‌نام، بازیابی پشتیبان، عدم کش HTML خصوصی، درگاه و باکت هدف را پیش از پایلوت بررسی کن.
- [ ] PSY-1.13 اجرای سناریوهای پایلوت، ثبت رخداد و روش پشتیبانی و پیگیری پرداخت. شواهد واقعی پذیرش و نتیجهٔ هر دو پایلوت را هنگام مجاز بودن انتشار ثبت کن.

**پایان فاز** — کارگاه رایگان و پولی، بلاگ و رسانه از پنل تا سایت در `PSY-A02` تا `PSY-A06` تأیید شده‌اند. شواهد دو کارگاه واقعی و محیط در `PSY-A10` برای عرضه ثبت می‌شود.

## PSY-2 — نسخهٔ ۲ · نوبت حضوری

[نوبت](modules/booking.md) · [نقش و حریم خصوصی](modules/platform.md)

- [ ] PSY-2.1 تکمیل schema، migration، OpenAPI و تست RLS درمانگر، زمان کاری، سانس، نوبت و تاریخچهٔ وضعیت.
- [ ] PSY-2.2 ساخت تقویم درمانگر، بازهٔ کاری، استثنا و تولید سانس‌های غیرهم‌پوشان. تغییر ساعت روی سانس آزاد اعمال شود و نوبت‌های قبلی قابل پیگیری بمانند.
- [ ] PSY-2.3 ساخت فهرست زمان آزاد و درخواست مهمان با نگه‌داشت موقت، محدودیت نرخ و پیگیری خصوصی. درخواست هم‌زمان برای یک سانس و انقضا را آزمون کن.
- [ ] PSY-2.4 ساخت تأیید، لغو، جابه‌جایی اتمیک و انقضای نوبت. برخورد جابه‌جایی با رزرو دیگر و کنترل دسترسی درمانگر و پذیرش را آزمون کن.
- [ ] PSY-2.5 ساخت صفحات عمومی و پنل نوبت و وضعیت و نمایش زمان تهران. دادهٔ شخصی از پاسخ عمومی، cache و log حذف شود.
- [ ] PSY-2.6 اجرای عملی فرایند پذیرش و سناریوهای حریم خصوصی و رزرو هم‌زمان. نتیجهٔ تست‌های مرورگر و پاک‌سازی داده را ثبت کن.

**پایان فاز** — درخواست، تأیید، لغو و جابه‌جایی نوبت برای دو تقویم مستقل و تست `PSY-A07` تأیید شده است.

## PSY-3 — نسخهٔ ۳ · دورهٔ ضبط‌شده

[دوره](modules/courses.md) · [پرداخت](modules/payments.md) · [رسانه](modules/blog-media.md)

- [ ] PSY-3.1 تکمیل schema، migration، RLS و OpenAPI دوره، درس، هویت خریدار و دسترسی خرید. یکتایی دسترسی فعال و snapshot دوره را پوشش بده.
- [ ] PSY-3.2 ساخت ورود، ثبت‌نام، بازیابی و نشست مستقل خریدار scoped به Tenant. خرید با حساب جاری و بازیابی کد یک‌بارمصرف را آزمون کن.
- [ ] PSY-3.3 ساخت پنل دوره و درس، پیش‌نویس و آرشیو و آپلود خصوصی و سهمیهٔ درس. جدایی فایل دوره از رسانهٔ بلاگ را در Backend آزمون کن.
- [ ] PSY-3.4 ساخت صفحهٔ فروش و checkout تک‌دوره با استفاده از سرویس پرداخت `PSY-1.5` تا `PSY-1.7`. Verify باید در همان تراکنش دسترسی بسازد. پرداخت تکراری و بازپرداخت را آزمون کن.
- [ ] PSY-3.5 ساخت حساب «دوره‌های من» و API صدور دسترسی کوتاه‌مدت پخش. تست بدون خرید، حساب دیگر، Tenant دیگر، پایان TTL و لغو دسترسی را اجرا کن.
- [ ] PSY-3.6 ساخت پخش و تمدید URL فیلم و ویس در مرورگر. Range و seek، قابلیت پخش با اینترنت موبایل و رد playlist یا فایل ناسازگار را روی باکت هدف بررسی کن.
- [ ] PSY-3.7 اجرای خرید تا پخش، آرشیو برای خریدار قبلی، بازپرداخت و هزینهٔ ذخیره و ترافیک را در محیط هدف ثبت کن.

**پایان فاز** — تست‌های `PSY-A08` و `PSY-A09`، خرید دوره تا پخش و جلوگیری از دسترسی بدون خرید را تأیید می‌کنند.

## PSY-4 — بهره‌برداری بعد از پایلوت

- [ ] PSY-4.1 گزارش شاخص‌های غیرشخصی ثبت‌نام، نوبت، فروش، خطا و مصرف رسانه در هر Tenant. آزمون جدایی گزارش و حذف اطلاعات شخصی را اجرا کن.
- [ ] PSY-4.2 تمرین بازیابی و بازبینی سیاست حذف داده، هزینه و ظرفیت باکت و شرایط پشتیبانی. شواهد هر نسخه و بازهٔ نگه‌داری را به‌روز کن.
- [ ] PSY-4.3 نیاز به کش HTML را اندازه بگیر. اگر لازم بود، فقط خانه، پروفایل و مطالب منتشرشده را با کلید Host و path و Outbox کش کن. پاسخ پویا یا خصوصی از کش مشترک کنار گذاشته می‌شود. تست HIT، BYPASS و purge همان Tenant را ثبت کن.
- [ ] PSY-4.4 نتیجهٔ پایلوت‌ها، هزینهٔ عملیاتی و سهمیهٔ رسانه را ثبت کن و قیمت اشتراک و محدودهٔ نسخهٔ بعد را با دادهٔ واقعی تعیین کن.

**پایان فاز** — آزمون‌های نسخه‌ها، گزارش پایلوت، بازیابی و رفتار کش ثبت شده‌اند. [سناریوهای پذیرش](ACCEPTANCE.md)
